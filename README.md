Now building under **HaruoDev**:

- **[Tamperlens](https://tamperlens.com)** — a Document Trust API that answers
  one specific question: *was this document edited after it was issued?*
  A deterministic engine (no ML, no third-party calls) with 36 signal families
  across PDFs, images and Office documents, running in production. Its public
  stance is "risk signals, not verdicts", and its numbers are measured and
  [published](https://tamperlens.com/evidence) — including the unflattering
  ones. The free checker on the homepage runs without signup.
- **[tamperlens-mcp](https://www.npmjs.com/package/tamperlens-mcp)** — MCP
  server for Tamperlens, on npm and the MCP Registry
  ([source](https://github.com/haruodev/tamperlens-mcp)).
- **[n8n-nodes-tamperlens](https://www.npmjs.com/package/n8n-nodes-tamperlens)**
  — n8n community node for Tamperlens, on npm
